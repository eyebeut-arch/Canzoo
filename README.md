# CANZOO APK v2

Projet Android natif Kotlin.

Fonctions de base :
- interface mobile
- chat local
- français, wolof, Pulaar Sénégal
- reconnaissance vocale Android
- synthèse vocale
- base Offline First
- GitHub Actions pour compiler l'APK

Important : le moteur IA génératif n'est pas encore embarqué dans cette v2. Les réponses sont locales de démonstration.

## Compilation automatique
1. Créer un dépôt GitHub.
2. Envoyer tout le contenu de ce dossier à la racine du dépôt.
3. GitHub Actions pourra compiler le projet.
4. L'APK sera récupérable dans l'onglet Actions > workflow > Artifacts.

Le wrapper Gradle complet peut être généré par Android Studio ou ajouté par le système de build avant compilation.
